# 小兔鲜儿（XiaoTuXian）电商项目技术文档

## 一、项目概述

**项目名称：** 小兔鲜儿鲜食电商平台
**技术定位：** 基于 uni-app 的三端统一开发电商应用（H5 / 微信小程序 / App），配套自建 Node.js 后端
**开发周期：** 从零搭建，包含前后端开发、数据库设计、第三方服务集成、AI 智能助手等完整功能

## 四、核心功能模块

### 4.1 电商核心功能

#### 商品模块
- **首页轮播图**：按分发位获取 Banner
- **分类浏览**：三级分类树，自动过滤空分类
- **商品详情**：SKU 选择、规格展示、相似商品推荐
- **搜索**：关键词搜索 + 搜索提示
- **热门推荐**：特惠/爆款/一站买全/新鲜好物四种类型
- **猜你喜欢**：分页无限滚动

#### 交易模块
- **购物车**：增删改查、全选/反选、SKU 去重
- **订单**：下单 → 支付 → 发货 → 收货 → 评价，6 种状态流转
- **支付**：模拟支付（开发环境）+ 微信支付预留
- **收货地址**：CRUD + 默认地址

#### 用户模块
- **多种登录**：账号密码 / 短信验证码 / 微信小程序 / 模拟登录
- **个人信息**：头像上传（OSS）、昵称、性别、生日等
- **分包加载**：会员中心和订单模块懒加载

### 4.2 AI 智能购物助手

**架构设计：**

```
用户消息 → 关键词意图识别 → LangChain Tool 调度 → MiMo LLM 生成回复
                              │
                              ├── search_goods（关键词搜索）
                              ├── category_goods（分类查询）
                              └── recommend_goods（随机推荐）
```

**技术要点：**

| 特性 | 实现方式 |
|------|---------|
| LLM 适配 | 自定义 `MiMoChatModel`（继承 `BaseChatModel`），绕过 LangChain 的 `ChatOpenAI` 兼容问题 |
| Tool 定义 | `DynamicStructuredTool` + Zod Schema，类型安全 |
| 意图识别 | 确定性关键词映射（17 个关键词 → 分类），LLM 兜底 |
| 对话记忆 | 内存 `Map<sessionId, ChatMessage[]>`，保留最近 10 轮 |
| 流式输出 | SSE（Server-Sent Events），H5 端逐字显示，小程序/App 降级为普通接口 |
| 图片分析 | OpenAI Vision 格式（多模态消息），支持美学分析、商品识别 |
| 降级策略 | API 异常时自动返回商品推荐，不影响用户体验 |

### 4.3 地图物流可视化

**三端适配方案：**

| 平台 | 地图引擎 | 路线绘制 | 标记点 |
|------|---------|---------|--------|
| H5 | 高德 JS API v2.0 | 贝塞尔曲线 Polyline | AMap.Marker |
| App | 高德静态地图图片 | 图片内 polyline | 图片内 markers |
| 小程序 | 原生 `<map>` 组件 | polyline 属性 | markers 属性 |

**后端：** 高德 REST API 地理编码 + 驾车路线规划，返回坐标数组

### 4.4 短信验证码登录

**流程：**

```
输入手机号 → 后端生成6位验证码 → 存入DB(5分钟有效)
     ↓
调用阿里云 SendSmsVerifyCode → 用户收到短信
     ↓
输入验证码 → 后端校验 → 新用户自动注册 → 返回 JWT
```

**安全措施：**
- 10 秒频率限制（同手机号）
- 验证码 5 分钟过期
- 验证码一次性使用
- 阿里云平台级频率控制

### 4.5 阿里云 OSS 头像上传

**流程：** 前端选择图片 → `uni.uploadFile` → 后端 Multer 内存存储 → 直传 OSS → 返回 URL

**图片代理：** `/proxy/image?url=xxx`，白名单防 SSRF（仅允许 3 个域名）

## 五、条件编译（三端适配核心）

uni-app 的条件编译是本项目实现"一套代码三端运行"的关键。

### 5.1 语法

```ts
// #ifdef H5
// 仅 H5 端执行的代码
// #endif

// #ifndef H5
// 非 H5 端（小程序/App）执行的代码
// #endif

// #ifdef MP-WEIXIN
// 仅微信小程序端执行
// #endif

// #ifdef APP-PLUS
// 仅 App 端执行
// #endif
```

### 5.2 项目中的条件编译分布（33 处）

| 模块 | 平台差异 | 涉及文件 |
|------|---------|---------|
| **API 地址** | H5 用 localhost，其他用局域网 IP | `config/index.ts` |
| **登录方式** | H5/App 账号密码，小程序微信授权 | `login.vue` |
| **AI 聊天** | H5 用 SSE 流式，其他用普通接口 | `ChatPanel.vue` |
| **图片读取** | H5 用 FileReader，App 用 plus.io，小程序用 getFileSystemManager | `ChatPanel.vue` |
| **地图渲染** | H5 用 JS API，App 用静态图片，小程序用原生 map | `LogisticsMap.vue` |
| **头像上传** | H5/App 用 uni.chooseImage，小程序额外处理 | `profile.vue` |
| **区域选择** | H5/App 用 picker，小程序用省市区组件 | `address-form.vue` |
| **骨架屏** | H5/App 有动画，小程序无 | `PageSkeleton.vue` |

## 六、数据库设计

### 6.1 数据库表结构（13 张表）

| 表名 | 用途 | 关键字段 |
|------|------|---------|
| `users` | 用户信息 | account, password(bcrypt), nickname, avatar |
| `banners` | 首页轮播图 | img_url, href_url, distribution_site |
| `categories` | 一级分类 | name, icon |
| `goods_categories` | 商品分类（支持多级） | parent_id, name, picture |
| `goods` | 商品主表 | name, price, main_pictures(JSON), category_id |
| `goods_skus` | 商品 SKU | goods_id, price, inventory, specs(JSON) |
| `goods_specs` | 商品规格 | goods_id, name, values(JSON) |
| `hot_items` | 热门推荐 | title, pictures(JSON), type |
| `addresses` | 收货地址 | user_id, receiver, full_location, is_default |
| `cart_items` | 购物车 | user_id, sku_id, count, selected |
| `orders` | 订单 | order_no, order_state, address_snapshot(JSON), pay_money |
| `order_skus` | 订单商品 | order_id, sku_id, name, quantity, cur_price |
| `sms_codes` | 验证码记录 | mobile, code, used, expires_at |

### 6.2 订单状态机

```
待付款(1) → 待发货(2) → 待收货(3) → 待评价(5) → 已完成(4)
    ↓            ↓           ↓
  取消(6)      退款       确认收货
```

## 七、安全设计

| 安全措施 | 实现方式 |
|---------|---------|
| **密码加密** | bcryptjs 哈希（10 轮 salt） |
| **JWT 认证** | 7 天有效期，中间件统一校验 |
| **SSRF 防护** | 图片代理白名单（仅 3 个域名） |
| **配置外置** | 所有密钥/密码在 `.env`，不入代码 |
| **频率限制** | 短信 10 秒间隔 + 阿里云平台级限制 |
| **请求限制** | JSON body 10MB 上限 |
| **CORS** | 允许跨域（开发环境） |

## 八、构建与部署

### 8.1 开发命令

```bash
# 前端
pnpm dev:h5              # H5 开发（localhost:5173）
pnpm dev:mp-weixin       # 微信小程序（dist/dev/mp-weixin）
pnpm dev:app             # App 端（需 HBuilderX）

# 后端
cd server && pnpm dev    # tsx watch 热重载
```

### 8.2 生产构建

```bash
# 前端
pnpm build:h5            # → dist/build/h5/
pnpm build:mp-weixin     # → dist/build/mp-weixin/
pnpm build:app           # → dist/build/app/

# 后端
cd server && pnpm build  # tsc → dist/
cd server && pnpm start  # node dist/app.js
```

### 8.3 部署架构

```
Nginx (443/80)
├── / → H5 静态文件
└── /api → Node.js :3000 (PM2 守护)
              └── MySQL :3306
```

## 九、项目亮点总结

### 9.1 技术亮点

1. **三端统一开发**：一套 Vue3 + TypeScript 代码，通过条件编译（33 处）适配 H5/小程序/App
2. **AI 智能助手**：LangChain 架构 + 自定义 MiMo 适配器 + Tool Calling + SSE 流式输出
3. **全链路 TypeScript**：前后端统一 TS，泛型 HTTP 封装，类型安全
4. **多端地图适配**：H5 用 JS API 贝塞尔曲线，App 用静态图片，小程序用原生组件
5. **SSE 逐字显示**：H5 端实现打字机效果，小程序/App 自动降级

### 9.2 工程亮点

6. **安全审计**：敏感配置外置 `.env`、SSRF 白名单、JWT 认证、bcrypt 加密
7. **后端 tsc 编译**：开发用 tsx，生产编译为纯 JS，PM2 守护
8. **条件编译三端构建**：H5/小程序/App 构建产物均验证通过
9. **分包懒加载**：会员中心和订单模块按需加载，首屏提速
10. **骨架屏 + 无限滚动**：提升用户体验

### 9.3 功能亮点

11. **完整电商链路**：商品浏览 → 购物车 → 下单 → 支付 → 物流 → 评价
12. **多种登录方式**：账号密码 / 短信验证码 / 微信授权 / 模拟登录
13. **AI 图片分析**：上传图片进行美学分析、商品识别、购买建议
14. **阿里云 OSS 直传**：头像上传不经后端中转，节省带宽
15. **数据爬虫**：自动化从远程 API 爬取商品数据填充本地数据库
